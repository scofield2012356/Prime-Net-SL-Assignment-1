# PrimeTrack Dart Prototype

PrimeTrack is a console-based prototype for recording and following up on client inquiries for the proposed PrimeNet SL workflow.

## Requirements

- Dart SDK installed and available in the terminal as `dart`.
- The program uses only Dart's built-in `dart:io` library.

## Run

From this folder, run:

```bash
dart run main.dart
```

## Menu

1. Record an inquiry
2. View all inquiries
3. Search by inquiry ID
4. Update inquiry status
5. View inquiry summary
0. Exit

Records are stored in memory and are cleared when the program closes. This prototype does not connect to PrimeNet systems, send email, or save personal data to a database.
